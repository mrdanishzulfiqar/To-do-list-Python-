🚀 Built a simple CLI Todo List Manager in Python!

To keep strengthening my core Python skills, I built a command-line Todo List application focused on practical data persistence and clean code structure.

🛠️ Key Features:
• Interactive terminal menu interface
• Persistent storage using JSON files (json module)
• Dynamic task tracking (View, Add, Complete, Delete)
• Error handling for user inputs using try/except blocks

Developing terminal applications like this is a great way to reinforce fundamental concepts like dictionaries, lists, file I/O operations, and modular function design.

📁 Code Breakdown:

Loads task data from todo_list.json if available.

Uses enumerate() to generate user-friendly indexed task lists.

Updates and saves the list state in real-time.
